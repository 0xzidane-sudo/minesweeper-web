الميزات: لعبة كاسحة ألغام تعمل محلياً، مستويات Beginner/Intermediate/Expert، لوحة مخصصة، Daily Puzzle بتاريخ اليوم، مؤقت، أعلام، كشف تلقائي للمناطق الفارغة، نتائج وإحصائيات محلية، لغات عربية/إنجليزية/فرنسية، تخطيط متجاوب وPWA.

ملاحظة: هذه إعادة تنفيذ مستقلة للعبة الأساسية. ميزات Daily Club والنتائج العالمية والمزامنة والخدمات الخلفية الأصلية ليست متصلة بخوادم التطبيق الأصلي.
